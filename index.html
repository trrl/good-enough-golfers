Round-by-Round Groups

Set up each round separately, with its own group size or number of groups. Uneven numbers are fine. The tool keeps students apart from classmates they've already worked with whenever it can.

Students

One name per line. Names stay in your browser.

Rounds

Roles

Every group gets each role, and the tool gives students roles they haven't had yet. In a group with fewer people than roles, someone takes two.

Pairing rules

Separate names with commas and put each set on its own line. Nobody on a line will share a group with anyone else on that line unless it can't be avoided. Use this for group leaders too: list them all on one line to spread them out.

A gentler version of the rule above. The tool tries to split these students up, but avoiding repeat partners comes first in later rounds.
